# PT Tools

PT 站点的自动化管理工具。

![](https://img.shields.io/badge/%E6%96%B0%E7%96%86%E8%90%8C%E6%A3%AE%E8%BD%AF%E4%BB%B6%E5%BC%80%E5%8F%91%E5%B7%A5%E4%BD%9C%E5%AE%A4-%E6%8F%90%E4%BE%9B%E6%8A%80%E6%9C%AF%E6%94%AF%E6%8C%81-blue)

## 简介

PT Tools 支持 RSS 自动下载、刷流与 IYUU 辅种，可汇总各 PT 站点的数据与登录状态，并管理 qBittorrent 和 Transmission 下载器。还可通过网页、手机 App、QQ 和 Telegram 查看运行状态与控制任务。

## 安装说明

- WebUI 默认端口为 `8080`。
- 数据持久化目录为 `/app/.pt-tools`，升级或重建容器时请保留该目录。
- 数据目录中的 `secret.key` 用于解密已保存的站点凭证，请妥善备份。
